### RULE 2: THREE-WAY AGREEMENT & DEFAULT TEXT PRESERVATION
Every customizable item in the template MUST have 3-way agreement between:
1. **Manifest Declaration (`wishmagic.json` -> `fields` array)**:
   Declares `id`, `type`, `label`, `required`, `defaultValue`, `placeholder`, and `binding`.
2. **HTML Binding (`index.html`)**:
   Has an element with `data-wm-field="<id>"` and `data-wm-type="<type>"` matching the exact same `id` and `type`, and containing the normal/default text inside the HTML element.
3. **Working Runtime (`js/template.js`)**:
   Listens for `window.addEventListener('message', ...)` and `window.addEventListener('wishmagic:data-updated', ...)` so when the user changes a value in the WishMagic Customizer, the template updates immediately in real time — and if the user does NOT customize a message or text field (or leaves it blank), the template's normal/default message or text remains unchanged!

MANDATORY vs OPTIONAL FIELD RULE:
- **ONLY `recipient_name` (Name) and `event_date` (Date of Birth / Celebration Date) MUST have `"required": true`** — the user is required to enter Name and DOB/Date.
- **ALL other messages, texts, titles, subtitles, quotes, quiz items, roasts, captions, sender name, and media fields (`custom_message`, `sender_name`, `hero_title`, `hero_subtitle`, `secret_note`, etc.) MUST have `"required": false`** and MUST include their complete normal text in `"defaultValue"` (and inside the HTML element in `index.html`) so that if the user does not customize them, they stay exactly as their normal template text!

NEVER declare a field in `wishmagic.json` without binding it in `index.html`, and NEVER put a customizable element in `index.html` without declaring it in `wishmagic.json`.

### RULE 7: MANDATORY LIVE RUNTIME BRIDGE (`js/template.js`)
Include this universal live hydration listener in `js/template.js` (and also include `<script src="/js/wishmagic-template-protocol.js"></script>` in `index.html` right before `js/template.js`). Notice how it preserves the original HTML text of every `[data-wm-field]` element if the user leaves any message or text field uncustomized:
```javascript
(function () {
  // Capture original normal text of all bound elements on initial load
  document.querySelectorAll('[data-wm-field], [data-wm]').forEach(function (el) {
    if (!el.hasAttribute('data-wm-original-text') && !['IMG', 'AUDIO', 'VIDEO', 'INPUT', 'TEXTAREA', 'SELECT'].includes(el.tagName)) {
      el.setAttribute('data-wm-original-text', el.textContent || '');
    }
  });

  function applyWishMagicPayload(data) {
    if (!data || typeof data !== 'object') return;
    if (window.WishMagicTemplate && typeof window.WishMagicTemplate.applyData === 'function') {
      window.WishMagicTemplate.applyData(data);
    }
    // Trigger any template-specific recalculation (e.g. countdown date update)
    if (data.event_date && typeof window.updateTemplateCountdown === 'function') {
      window.updateTemplateCountdown(data.event_date);
    }
  }

  window.addEventListener('message', function (event) {
    if (!event.data || typeof event.data !== 'object') return;
    if (
      event.data.type === 'WISHMAGIC_INIT' ||
      event.data.type === 'WISHMAGIC_LIVE_UPDATE' ||
      event.data.type === 'WISHMAGIC_UPDATE'
    ) {
      applyWishMagicPayload(event.data.payload);
    }
  });

  window.addEventListener('wishmagic:data-updated', function (event) {
    if (event.detail && typeof window.updateTemplateCountdown === 'function' && event.detail.event_date) {
      window.updateTemplateCountdown(event.detail.event_date);
    }
  });
})();
```
